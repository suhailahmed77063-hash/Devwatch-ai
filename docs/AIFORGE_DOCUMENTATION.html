1. Overview

AIForge is a full-stack AI-powered website and application builder SaaS platform that enables users to create production-ready websites and web applications using natural language prompts.

🤖 AI Website Generation

Create multi-page websites from text prompts with sections, SEO, and responsive design.

🛠️ AI App Builder

Generate full-stack TypeScript applications with Express, React, Prisma, and JWT auth.

🎨 Visual Editor

Real-time website editing with live preview and AI assistant.

🚀 Auto-Deploy

Automatic deployment to production with live URL.

4. Getting Started

Prerequisites

  • Node.js 18+
  • npm or yarn
  • PostgreSQL database (or Neon)
  • OpenAI API key

Installation

# Clone the repository
git clone https://github.com/your-username/aiforge.git
cd aiforge

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your configuration

# Generate Prisma client
npx prisma generate

# Run database migrations
npx prisma migrate dev

# Start development server
npm run dev

9. Troubleshooting

⚠️ "AI service is temporarily unavailable"
Cause: OpenAI API error (usually 400 or 500)
Solution: Check OPENAI_API_KEY, verify model availability, check API quota
⚠️ "DATABASE_URL is not configured"
Cause: Missing database connection
Solution: Create Neon PostgreSQL database, add DATABASE_URL to Vercel env vars
